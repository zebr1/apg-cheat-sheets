Clone a repository locally:
`git clone <repository-url>`

Clone a repository locally forcing authentication with a specific user:
`git clone https://<username>>@github.com/<org-name>/<repo_name>.git`

Clone a Gist locally:
`git clone https://gist.github.com/your-gist-id.git`

Create a branch and check it out:
`git checkout -b newBranchName`

Commit files with a message
`git commit -m "Add a helpful commit message"`
