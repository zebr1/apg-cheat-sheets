# APG Cheat Sheets

A collection of cheat sheets for various technologies and tools commonly used in data engineering and cloud computing.

## Available Cheat Sheets

- [PowerShell](powershell.md) - Windows PowerShell scripting and command reference
- [Databricks CLI](databricks-cli.md) - Databricks command-line interface reference
- [Fabric CLI](fabric-cli.md) - Microsoft Fabric command-line interface reference
- [PySpark](pyspark.md) - PySpark API and operations reference

## Usage

Each cheat sheet is organized by category with practical examples and common use cases. Navigate to the individual files to explore the specific technology.
